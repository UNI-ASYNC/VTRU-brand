# V2 — general brand templates

V2 is a separate collection of general image templates for the five ecosystem brands. It uses the supplied brand marks and the existing website wording recorded in the [copy-source inventory](reports/COPY-SOURCES.md).

**[Browse V2 images](GALLERY.md)** · **[How to use the templates](USAGE-GUIDE.md)** · **[Version and evidence notes](VERSION-NOTES.md)** · **[V2 downloads](https://github.com/UNI-ASYNC/VTRU-brand/tree/main/downloads/v2)**

These files are static canvases for social profile covers, feed posts, Stories/Reels, video thumbnails, website headers and announcements. They provide a logo, type placement and open space where the team can add its existing imagery. They are image assets rather than working websites, applications or publishing tools.

## What V2 changes

- Supplied ZIP logos remain the artwork source, with their original geometry, lettering, proportions and colors.
- Marketing text comes from the current official pages, copied exactly or omitted. Functional fields such as `[Headline]`, `[Date]` and `[Details]` are editable template fields.
- Intended image areas are left open. V2 does not add galaxy artwork, orbital/node diagrams, grids, decorative balls, invented icons or new promotional slogans to occupy that space.
- White is the working canvas. It is not a proposed new brand palette. DejaVu Sans is a neutral editable template font, not a claim about the brands' official typography.

## Choose a file

| File type | Use |
|---|---|
| PNG | A rendered image for review or upload after the template's content is complete |
| SVG | An editable layout for adding the team's imagery and updating permitted text fields |
| DOCX | Editable stationery with document content, headers, footers and contact fields |
| PDF | A fixed layout or preview; letterhead PDFs are A4 RGB layouts without bleed |

The [usage guide](USAGE-GUIDE.md) explains the platform canvases, empty artwork area and editing steps. The [V2 gallery](GALLERY.md) identifies each asset's intended use so a cover, post and document header are easy to distinguish.
