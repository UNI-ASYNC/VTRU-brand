# V2 supplemental templates

These files are neutral, editable layouts using the supplied brand marks. They do not introduce campaign slogans, galaxy/node/grid illustrations, or decorative side panels. V1 is preserved separately as evidence.

- **Announcements:** square post layouts with editable `[Headline]`, `[Date]` and `[Details]` fields. Image placement guides are hidden from PNG exports; the open space is for existing owner-supplied imagery.
- **Document headers:** standard and compact light-background layouts with an editable document-title field.
- **Profile images:** three arrangements of existing source logo/logomark variants. No new avatar symbol was invented.
- **LinkedIn, Discord and website layouts:** format-specific logo placement and wording copied exactly from the current website copy inventory.
- **Letterheads:** formal, office and technical A4 stationery supplied separately in DOCX, SVG, PDF and 300 dpi PNG.

SVG and DOCX are editable files. PNG and PDF are presentation exports. DejaVu Sans is a neutral template font, not a claim about an official brand typeface. The same exact source SVG is embedded in each SVG master; Scope raster exports use its untouched paired high-resolution source PNG for sharpness.
