# Pretrend — V2 A4 letterheads

Three neutral layouts: formal, office and technical. Each has an editable DOCX, a source-preserving SVG, an A4 RGB PDF without bleed, and a 2480 × 3508 PNG at300dpi. The writing area is intentionally blank.

The full-color supplied logo is unchanged. Header/footer rules are functional neutral gray; there are no added illustrations, decorative motifs or marketing slogans. Bracketed contact and document fields are editable placeholders. Double-click the DOCX header/footer to edit them. The technical DOCX includes a real PAGE field.

Template text uses DejaVu Sans as a neutral editable font, not a claimed official brand font. DOCX header/footer structure and original source-image bytes were checked; visual rendering in Word/LibreOffice was not performed. PDFs and PNGs are the visual layout reference.

For VTRU Scope, the SVG embeds the supplied source SVG; PDF and PNG exports use the untouched paired high-resolution source PNG at the same position for clarity.
