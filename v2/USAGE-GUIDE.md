# Using the V2 templates

These are general layouts for static images and documents. A banner is a wide profile or channel cover; a post is an image in a feed; a thumbnail identifies a video; a website header is artwork a developer can place in an existing site. The files do not publish themselves or add website functionality.

## Add the team's imagery

1. Choose the layout for the intended platform or document.
2. Open its SVG master in a compatible vector editor. Use DOCX for stationery content.
3. Add existing owner-supplied imagery to the empty `client-artwork` group. Some layouts also include a hidden image-placement guide. The open space is deliberate and should remain open until suitable imagery is supplied.
4. Keep the supplied logo proportions and artwork intact. Preserve legibility when placing an image behind or beside text.
5. Use the exact sourced phrase recorded for the brand, or omit it. Fill bracketed functional fields with the actual announcement or document content. Do not turn an empty field into a newly invented brand slogan.
6. Export a PNG at the template's original pixel dimensions. Inspect the result in the platform's upload preview before publishing.

Neutral template typography can be edited to the team's confirmed existing font system. DejaVu Sans is used for editable working layouts; its presence does not designate it as an official brand font.

## Crop and export checks

YouTube's 2560 × 1440 channel canvas keeps essential content within a centered **1544 × 422** production safe area. The full image can look spacious because desktop/mobile views show a much narrower center region. X layouts reserve space around the profile-photo area and keep important content clear of the top and bottom edges. Facebook and Rumble displays can crop or overlap images differently by account and device.

After adding imagery, recheck logo and text placement in the actual target account. Keep the original output size and avoid stretching a finished PNG to fit another aspect ratio. The blank areas allow the same approved imagery to be placed appropriately for each surface.

Letterhead PDFs are **A4 RGB layouts without bleed**. They are not represented as certified commercial-print PDF/X masters. DOCX files are editable; final page flow should be checked in the team's word processor. PNG and PDF exports provide a fixed-layout reference.
