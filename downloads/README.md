# ZIP downloads

The GitHub repository contains the actual browsable images, editable files, guides and reports. ZIP packages are attached to the [v1.0.0 release](https://github.com/UNI-ASYNC/VTRU-brand/releases/tag/v1.0.0).

| Package | Contents |
|---|---|
| `Vitruveo-Ecosystem-Brand-System.zip` | Original complete brand-system delivery |
| `Vitruveo-Neon-Social-Banners.zip` | Complete neon social-banner delivery |
| `01-Ecosystem-Four-Brands-PNGs.zip` | Four-brand neon PNGs, arranged by platform |
| `02-Ecosystem-Five-Brands-PNGs.zip` | Five-brand neon PNGs, arranged by platform |
| `03-Vitruveo-PNGs.zip` | Vitruveo neon PNGs |
| `04-Vertical-Foundation-PNGs.zip` | Vertical Foundation neon PNGs |
| `05-Pretrend-PNGs.zip` | Pretrend neon PNGs |
| `06-AI-Wars-PNGs.zip` | AI Wars neon PNGs |
| `07-VTRU-Scope-PNGs.zip` | VTRU Scope neon PNGs |
| `08-Editable-SVG-Masters.zip` | All 79 neon SVG masters with shared backgrounds, fonts and supporting documentation |

The eight numbered packages are each smaller than 10 MB. Download those ZIPs individually when a smaller file is more convenient. The repository itself can also be downloaded with **Code → Download ZIP**.

Original source brand-kit ZIPs are checked into [source-brand-kits](../source-brand-kits/) and remain directly downloadable there.
