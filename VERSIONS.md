# Versions and provenance

| Material | Meaning | Browse |
|---|---|---|
| Supplied original artwork | The five actual brand kits. These are the source marks, not newly designed substitutes. Public kit bytes matched the uploaded archives. | [Source kits](source-brand-kits/) |
| V1 evidence | The first project deliveries and research. Some layouts, motifs, backgrounds and sample slogans were created during this project. They are retained as evidence of that first proposal, not presented as legacy official artwork. | [V1 image gallery](GALLERY.md), [frozen V1 snapshot](https://github.com/UNI-ASYNC/VTRU-brand/tree/v1.0.0) |
| V2 general templates | A separate new collection using supplied marks and exact existing website wording, or functional editable fields. Owner imagery areas remain open. No new decorative imagery or marketing slogans are supplied in V2. | [V2 overview](v2/README.md), [V2 gallery](v2/GALLERY.md), [V2 downloads](downloads/v2/) |

V1's artwork, source files, reports, audits and ZIPs remain unchanged. The main README and gallery navigation identify the versions; their original content is also preserved in Git tag `v1.0.0`.

V2 is template authoring, not a new brand direction. Its blank working canvas and editable type placement are practical layout choices for existing imagery and copy. The five protected marks retain their supplied geometry, colors and lettering.

The website copy inventory records the exact selected wording and source URLs, checked on November 14, 2026. New marketing claims must not be inferred from the templates.
