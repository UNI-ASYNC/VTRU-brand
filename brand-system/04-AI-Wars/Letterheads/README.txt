DOCX files are editable Word templates with real repeating headers and footers.
Start typing in the blank body. Double-click the header/footer to replace bracketed
contact or reference placeholders. The technical DOCX page number updates in Word.
The supplied source logo is an embedded image, with its proportions preserved.
Typography uses DejaVu Sans; install the font or select a substitute if unavailable.
Word processors may reflow layout slightly. Check the final document before printing.

PDF and SVG files are blank A4 visual masters; PNGs are 300 dpi RGB templates.
PDFs retain the supplied vector artwork. All have white backgrounds and no bleed.
They are suitable for office printing; a commercial printer may request CMYK/PDF-X.
Replace contact placeholders before publishing or printing official correspondence.
No legal entity details, physical address, or ownership statement has been invented.
